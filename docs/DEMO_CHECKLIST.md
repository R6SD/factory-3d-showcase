# 演示 Checklist（1.4.3）

可勾选、可复现。`/admin` 的按钮和文案来自当前 `main` 的 `src/ui/admin/`；其余页面来自 `src/app.jsx` 与 `src/data/`。预期结果写的是现在页面上会出现的字，不是未合并 Issue 的目标文案。

标了 **仅桌面** 的步骤需要 Windows 上的 Electron（安装包或 `npm run desktop`）。其余步骤在浏览器里完成。无头核对使用生产预览，**不要**设置 `VITE_BASE`：

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 <http://127.0.0.1:4173/>。没有 Electron 时，`/api/data/business` 与 `/api/config` 会 404，业务数据用浏览器里的种子数据。这不是页面崩溃。

未纳入本清单（Issue 仍开放，页面上没有对应能力）：

- #7 设备拾取 / 状态色 / 详情侧栏：点击场景中的设备不会打开侧栏。
- #8 性能预算面板：不要把三维页上的 **FPS** 按钮当成 #8。FPS 是已有的性能监控（帧率、渲染/秒、跳过/秒、GL调用/帧、三角面/帧、立体模式）。

人员种子共 **15** 人（`src/data/seed.js`），根节点是 **王建国**。产出条数随「今天」变化，清单里只比较导入前后的差值。

## 1. 三维主路径 `/`

- [ ] 打开 <http://127.0.0.1:4173/>。
  - 顶栏品牌为「工厂智能可视化」，`h1` 为「场地总览」。
  - 场景标题区小字为 `FACTORY DIGITAL TWIN`，`h2` 为「场地总览」。
  - 存在 `.three canvas`，画布宽高都大于 0。
  - `.webgl-context-lost` 的 `display` 为 `none`。
  - 画布不是整张纯黑：默认工厂模型（传送带、管道、储罐等）占住一部分非黑像素。背景本身是黑的。
  - 右下角出现「网格」「三角面」「材质」（`.model-info-badge`，场景就绪后约 1.5 秒内出现）。
  - 页脚有「拖动旋转 · 滚轮缩放 · 双击归位」和「WEBGL 2.0」。

- [ ] **镜头旋转。** 在画布上按住左键拖动。
  - `window.__factorySceneRuntime.camera.position` 发生变化。
  - 左上角罗盘指针随相机方向转动。

- [ ] **镜头缩放。** 指针放在画布上滚动滚轮。
  - 相机到 `control.target` 的距离发生变化。

- [ ] **重置视角。** 先拖动或滚轮，使相机离开初始位置，然后点击操作栏按钮「重置视角」（或在焦点不在输入框时按 `R`）。
  - 相机回到适配当前模型的距离（`SceneRuntime._fit`）。
  - 页脚写了「双击归位」。当前 `main`（#23）在空白处双击会在 680ms 内缓动归位。1.4.3（#23 合入前的 `0dbb2cb`）没有双击监听，双击画布不会归位，归位以「重置视角」和 `R` 为准。`main` 上 [#27](https://github.com/R6SD/factory-3d-showcase/issues/27) 仍开放、修复未合入：归位动画大约一秒内再点预设视角或按 `R` / `T` / `F` / `S`，相机会被拉回；在已隐藏网格原来的位置双击也不会归位。

- [ ] **场景视角。** 操作栏三个预设（`title`）：「顶视图」按钮文字 `T`、「前视图」`F`、「侧视图」`S`，以及「默认视角」（齿轮图标，`title="默认视角"`）。
  - 点 `T` 后相机在模型正上方。
  - 点 `F`、`S` 后改为正前、正侧，机位再次明显变化。
  - 点「默认视角」后回到斜向（模型的右前上方），不再贴着某一根轴。这一档和「重置视角」不是同一个距离：重置走 `_fit`，默认视角走 `setView('default')`（约模型最大尺寸的 2.2×1.1）。把滚轮拉开之后，只点「默认视角」不会收回 `_fit` 那一档距离。
  - 罗盘上的 `N` 调用前视，`E` 调用侧视，与 `F` / `S` 同一套 `setView`。
  - 默认展示模式是「标准」，场景会缓慢自转（`rotationSpeed` 0.3）。看缩放和重置时以相机到模型的距离为准，不要把自转当成操作失效。

- [ ] **侧栏路由。** 默认 `nav` 是 `mini`：侧栏宽 77px，链接文字被隐藏，`title` 仍在。依次点击 `aside a`：
  1. `title="模型库"` → 地址 `/models`，顶栏 `h1`「模型库」
  2. `title="产能看板"` → `/capacity`，`h1`「产能看板」
  3. `title="组织关系"` → `/organization`，`h1`「组织关系」
  4. `title="设置中心"` → `/settings`，`h1`「设置中心」
  5. `title="场地总览"` → `/`，`h1`「场地总览」，画布仍在

  若要看到侧栏文字：点 `title="切换导航模式"` **两次**（`mini` → `overlay` → `open`）。`open` 时侧栏展开，「场地总览 / 模型库 / 产能看板 / 组织关系 / 设置中心」可见。

## 7. 构建

在仓库根目录、不设置 `VITE_BASE` 时记录（2026-10-19，Node v22.23.3，已合入 `0dbb2cb`）：

```text
$ npm ci
退出码 0

$ npm test
> factory-3d-showcase@1.4.3 test
> vitest run

 Test Files  17 passed (17)
      Tests  147 passed (147)
退出码 0

$ npm run build
> factory-3d-showcase@1.4.3 build
> vite build
✓ built in 6.06s
退出码 0
```

`npm run build` 会打印 chunk 大于 500 kB 的警告（`three` 与 `exceljs`）。退出码仍是 0，不把这条警告当成构建失败。

子路径构建不在本清单的点击步骤里。需要时另跑：

```bash
VITE_BASE=/factory-3d-showcase/ npm run build
```

## 8. 仅桌面、本清单不在浏览器里打勾的项

- [ ] **仅桌面。** `npm run package:win` 在 `release/` 生成 README 中的两个文件：`工厂 Web3D 工作台 Setup 1.4.3.exe`、`工厂 Web3D 工作台 1.4.3.exe`。安装到 `D:\工厂 Web3D 工作台` 后，双击 `工厂 Web3D 工作台.exe`，浏览器打开 `http://127.0.0.1:43891/`。
- [ ] **仅桌面。** 设置中心 → 数据与集成的来源为「本地后端服务（已落盘）」。
- [ ] **仅桌面。** 照片上传成功，见第 2 节。
- [ ] **仅桌面。** 设置中心 → 常规 → 「退出并关闭服务」并确认后，本机服务停止，页面标题为「服务已关闭」。浏览器预览里这个按钮也在，但没有服务可关。
