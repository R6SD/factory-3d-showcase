# 标签使用模型局部坐标而非屏幕坐标

标签的锚点存储为模型局部坐标系下的三维坐标（`{x, y, z}`），每帧通过 `model.localToWorld()` 转换为世界坐标，再投影到屏幕空间定位标签 DOM。

原因：屏幕坐标标签在模型旋转后会指向错误位置。局部坐标绑定到模型表面的固定点，模型旋转/缩放/平移时锚点跟随移动，标签始终指向正确的模型位置。这也使得标签可以在模型切换后保留（同一模型的标签集独立存储）。

存储格式：`{ id, title, description, color, local: {x, y, z} }`，按模型名分组存储在 localStorage 和后端 JSON 文件中。

## Consequences

- 标签在模型任意旋转状态下都指向正确位置
- 需每帧执行 localToWorld 和投影计算（已优化为仅在有标签时运行）
- 模型几何变更后标签锚点可能偏移
