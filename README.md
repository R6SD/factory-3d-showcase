# 工厂 Web3D 工作台

一个纯前端的工厂三维展示与企业工作台。支持本地模型导入、场景与光影调节、可编辑的三维悬浮标签、模型库、组织关系和中英文界面。

## 快速开始

### 直接使用 Windows 程序（推荐）

运行安装包后，程序默认安装到：

```text
D:\工厂 Web3D 工作台
```

双击 `工厂 Web3D 工作台.exe`。程序会启动仅绑定本机的固定服务地址 `http://127.0.0.1:43891/`，并自动调用默认浏览器打开页面。固定地址可保证模型选择、场景设置和悬浮标签在下次启动时继续恢复。

退出服务：打开 **设置中心 → 常规 → 退出并关闭服务**。卸载程序位于：

```text
D:\工厂 Web3D 工作台\unins000.exe
```

导入的模型存放在：

```text
%APPDATA%\Factory Web3D Workbench\models
```

该目录独立于安装目录，升级或卸载程序时不会自动删除模型文件。

## 在全新 Windows 电脑配置开发环境

### 1. 安装必备软件

- Windows 10/11 64 位
- [Node.js LTS](https://nodejs.org/)（建议 22 LTS 或更新版本）
- Git（仅在需要从仓库获取源码时安装）

安装完成后，在 PowerShell 验证：

```powershell
node --version
npm --version
```

### 2. 获取并安装项目依赖

将项目文件复制到本机，例如 `D:\projects\factory-3d-showcase`，然后在该目录打开 PowerShell：

```powershell
cd D:\projects\factory-3d-showcase
npm install
```

首次安装会下载前端、Three.js 与 Windows 打包依赖，耗时取决于网络速度。

### 3. 启动开发服务

```powershell
npm run dev -- --host 127.0.0.1 --port 4173
```

浏览器访问：<http://127.0.0.1:4173/>

停止服务：在 PowerShell 中按 `Ctrl + C`。

### 4. 生成生产版本

```powershell
npm run build
```

生成的网页文件在 `dist/`。该目录是构建产物，不应手工修改。

### 5. 生成 Windows 安装包与免安装版

```powershell
npm run package:win
```

输出默认位于 `release/`：

- `工厂 Web3D 工作台 Setup 1.1.0.exe`：安装版。
- `工厂 Web3D 工作台 1.1.0.exe`：免安装版。

安装版默认安装到 `D:\工厂 Web3D 工作台`，并生成 `unins000.exe` 用于卸载。

## 功能说明

- 导入 GLB、glTF、FBX、OBJ 模型（单文件最大 200 MB），支持拖拽文件到三维场景区域直接导入。
- 导入模型会保存到程序指定模型目录，可在模型库中再次展示或删除；切换工作页面和重新启动程序后会自动恢复当前模型。
- 在模型表面右键创建悬浮标签；标签按模型独立保存，文本可编辑，并跟随模型与镜头移动。
- 三种环境预设、环境光、主光、阴影柔化、阴影质量、曝光与镜头控制；支持太阳光照昼夜交替。
- 默认工厂场景包含传送带、工业管道、储罐、警示柱、环境粒子与动态照明。
- 模型轮播：可在设置中心选择多个模型自动轮换展示。
- 裸眼 3D：运动视差（移动鼠标即有出屏纵深，无需眼镜）、视差屏障、并排立体、红蓝立体五种模式，可在三维页一键切换或在设置中调节视差强度。
- 产能、场地、人员、组织关系由本地数据层统一管理并持久化（桌面端落盘、浏览器端本地存储），支持人员增删改，可整体替换为 MES/IoT/HR 接口。
- 设置中心提供中英文、品牌图标、导航和场景配置；配置保存在本机浏览器。

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `R` | 重置三维视角 |
| `F` | 全屏查看器 |
| `L` | 显示/隐藏悬浮标签 |

### 三维查看器

- **视角预设**：操作栏提供顶视（T）、前视（F）、侧视（S）和默认视角一键切换。
- **显示模式**：实体 / 线框 / 点云三种渲染模式循环切换。
- **场景截图**：点击"截图"按钮可将当前三维画面导出为 PNG 图片。
- **模型信息**：右下角实时显示当前模型的网格数、三角面数和材质数。
- **性能监控**：点击"FPS"按钮开启性能面板，实时显示帧率、三角面数、绘制调用。
- **层次结构**：点击"层级"按钮打开模型节点树，支持展开/折叠、点击聚焦、显隐切换。
- **实时时钟**：右上角显示系统时间。
- **拖拽导入**：将模型文件直接拖到三维场景区域即可导入。
- **WebGL 恢复**：图形上下文意外丢失时自动提示并尝试恢复。

### 产能看板

- KPI 指标条：本月总产出（含环比）、日均产出、人均产出、计划达成率（三档配色）、重点关注（环比下滑部门），数值带平滑滚动动效。
- 近 6 个月产出趋势柱状图，点击柱体切换月份。
- 部门产能列表支持点击下钻：工段产出与个人排名联动过滤，面包屑返回。
- 部门/工段环比徽标（涨红跌绿），线体日产能柱状图与个人产出排名（大头照/半身照切换）保留。
- 看板文案支持中英文切换（英文月份显示 Jan–Dec 缩写）。

### 后端数据管理

- 从展示端顶部标题栏或访问 `/admin` 进入后端管理页，集中维护业务数据、照片库、模型库与设置中心。
- 业务数据分为「人员与组织」「产出记录」「月度计划」三个子标签：
  - 人员与组织、产出记录支持新增/编辑/删除、Excel 导入/导出。
  - 月度计划展示近 6 个月的计划产量、实际产出与达成率，支持逐月直接修改并保存，也支持 Excel 批量导入/导出；达成率 ≥100% 绿色 / ≥90% 黄色 / <90% 红色。
- 照片库按文件名规则自动匹配员工大头照（`姓名.jpg` / `工号.jpg`）与半身照（`姓名-半身.jpg` / `工号-half.jpg`）。
- v1.4.1 修复 `/admin` 页面布局错位：搜索栏双边框、表格窄屏溢出、表单字段塌缩、头部与主体左右不对齐、编辑抽屉顶部空隙等问题。

### 设置中心

- **配置管理**：支持将场景、品牌、导航等配置导出为 JSON 文件，或从文件导入恢复。
- **本地存储信息**：显示配置数据大小、已登记模型数、当前语言与应用版本。
- 中英文界面、品牌图标上传、导航模式切换、场景光影实时预览。

## 常见问题

### 程序启动后没有打开浏览器

检查默认浏览器是否被系统策略禁用；也可在启动后查看浏览器地址栏中是否打开了 `http://127.0.0.1:<端口>/`。程序仅允许本机访问，不会暴露到局域网。

### 模型库显示“需要重新导入”

这是旧版浏览器记录没有保存原始文件导致的。重新导入同名模型后，程序会把文件保存到指定模型目录，之后可重复切换展示。

### 为什么免安装版启动较慢

便携 EXE 每次运行都需要在临时目录解压，建议长期使用安装版。
